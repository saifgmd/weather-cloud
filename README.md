# 🌧️ Weather Cloud (سحابة الطقس)

> **تجربة نافذة مطرية تفاعلية مع تأثير WebGL، ساعة حية، وطقس في الوقت الفعلي.**

تم التطوير بواسطة **SAIF G.M.D**

---

## 🌟 نظرة عامة
**Weather Cloud** هو تطبيق ويب تقدمي (PWA) يحاكي نافذة مطرية واقعية. يجمع بين محرك مطر WebGL مخصص، وواجهة زجاجية أنيقة (Glassmorphism) مستوحاة من iOS، وبيانات طقس حية. يعمل كخلفية مهدئة، أو أداة طقس، أو تطبيق قابل للتثبيت على أي جهاز.

---

## ✨ المميزات
- 🎨 **واجهة زجاجية عصرية**: تصميم أنيق ومينيمال.
- 🌧️ **محرك مطر WebGL مخصص**: تأثير قطرات واقعي (بدون مكتبات خارجية).
- ⏰ **ساعة حية**: تعرض الوقت، التاريخ، واليوم.
- 🌤️ **طقس فوري**: درجة الحرارة، الرطوبة، الرياح، وتوقعات لـ 3 ساعات.
- 📍 **تحديد الموقع تلقائياً**: تحويل الإحداثيات إلى اسم المدينة (Reverse Geocoding).
- 🔊 **صوت مطر هادئ**: مع التحكم في مستوى الصوت.
- 🖼️ **خلفيات مخصصة**: صور جاهزة، رابط خارجي، أو رفع ملفك الخاص.
- 📱 **تطبيق PWA**: قابل للتثبيت ويعمل بدون إنترنت (Offline).
- 🎛️ **تخصيص كامل**: تعديل التمويه، السطوع، كثافة المطر، والألوان.
- ♿ **إمكانية الوصول**: دعم لوحة المفاتيح وقارئات الشاشة.

---

## 🛠️ التقنيات
- **HTML5** و **CSS3**
- **JavaScript** (Vanilla)
- **WebGL** (تأثير المطر)
- **Service Worker** و **Manifest** (PWA)
- **Open-Meteo API** (بيانات الطقس)
- **BigDataCloud API** (اسم المدينة)
